# Роли

| Роль | Кто | Что делает |
|---|---|---|
| **Лидер** | Ответственный по бригаде либо наиболее опытный сотрудник | Проводит осмотр пациента, собирает анамнез, руководит оказанием помощи, принимает тактические решения на месте вызова, выполняет манипуляции по устранению жизнеугрожающих состояний |
| **Адъютор** | Помощник: фельдшер или медицинская сестра | Выполняет манипуляции по указанию лидера, обеспечивает первичную респираторную поддержку (масочная оксигенотерапия, ручная вентиляция), выполняет измерения и обеспечивает сосудистый доступ |

Роли распределяются **до прибытия на место вызова**, а не у пациента. Манипуляции по устранению жизнеугрожающих состояний — остановка кровотечения, устранение асфиксии, пункция плевральной полости — выполняет любой из двоих: лидер самостоятельно либо адъютор по указанию лидера.

Каждое назначение адресуется конкретному человеку, исполнение подтверждается голосом, результат докладывается лидеру числом: «сатурация 82», «давление 70 на 40», «глюкоза 3,1». Формулировка «сделано» без результата не заменяет доклада.

# Этап 0. До прибытия на вызов

::: roli
| Лидер | Адъютор |
|---|---|
| Распределяет роли и проводит краткий инструктаж по порядку действий на вызове | Слушает инструктаж, уточняет, что берёт на себя |
| Просматривает данные ЕМИАС и личного кабинета ФОМС, данные опроса диспетчера, наличие повторных вызовов к этому пациенту | Готовит оборудование по поводу к вызову, определяет, кто что несёт |
| По возможности связывается с вызывающим для уточнения состояния | Включает монитор, готовит кислородную магистраль и раствор для инфузии, размещает оборудование в салоне так, чтобы выйти с ним без задержки |
:::

Проверка личной и инфекционной безопасности — оба: верхняя одежда застёгнута, карманы закрыты, волосы убраны, часы и браслеты сняты; перчатки и маски у обоих; защитные очки или экран обязательны при работе с дыхательными путями.

::: povod
| Повод к вызову | Что берётся дополнительно к общепрофильной укладке, базовому ургентному набору и абонентскому комплексу |
|---|---|
| «Без сознания», «нарушение сознания с угрозой жизни», «нарушение дыхания с угрозой жизни», «не дышит», «хрипит», «посинел», «подавился, не дышит» | Реанимационный набор по возрасту, источник кислорода, дефибриллятор |
| Вызов «на себя» с реанимационным диагнозом | То же и аппарат искусственной вентиляции лёгких |
:::

# Этап 1. Прибытие и первичная оценка

::: roli
| Лидер | Адъютор |
|---|---|
| Оценивает безопасность места вызова — оба, вслух, до подхода к пациенту | Оценивает безопасность места вызова |
| Оценка «с порога»: положение пациента, общий вид, целенаправленные движения, цвет кожи, приблизительный возраст, пол, рост и вес, доступность осмотру, видимые повреждения | Размещает оборудование и монитор у пациента со стороны, свободной для лидера |
| «Что случилось?» — первый вопрос окружающим | Готовит пульсоксиметр и глюкометр к работе |
:::

# Этап 2. Сознание

Оценка уровня сознания выполняется обоими: лидер обращается к пациенту, адъютор наблюдает за дыханием и движениями.

| Шкала AVPU | Что означает |
|---|---|
| **A** (alert) | В сознании, активен, сознание ясное |
| **V** (verbal) | Реагирует на голос: оглушение, сопор |
| **P** (pain) | Реагирует на боль: сопор, неглубокая кома |
| **U** (unresponsive) | Не реагирует: глубокая кома |

**Отсутствие сознания и отсутствие дыхания — немедленное начало сердечно-лёгочной реанимации; осмотр по ABCDE прекращается.**

# A. Дыхательные пути

При ясном сознании и активной речи проходимость дыхательных путей сомнений не вызывает, и оценка не требуется. При сниженном сознании оценка проходимости и оценка дыхания проводятся одновременно.

::: roli3
| Ситуация | Лидер | Адъютор |
|---|---|---|
| **Проходимы** | Оценка проходимости ВДП, переход к B | Наблюдение, подготовка оборудования к следующему этапу |
| **Храп** | Оценка проходимости → выдвижение нижней челюсти → повторная оценка проходимости | Установка воздуховода |
| **Булькающее дыхание** | Оценка проходимости → повторная оценка проходимости | Санация верхних дыхательных путей |
| **Стридор** | Оценка проходимости → решение о протекции дыхательных путей → восстановление проходимости при жизнеугрожающем состоянии | Санация верхних дыхательных путей → вентиляция дыхательным мешком |
| **Апноэ** | Начало сердечно-лёгочной реанимации | Компрессии либо вентиляция по указанию лидера |
:::

Протезирование дыхательных путей выполняется последовательно и только при неэффективности предыдущего метода: воздуховод, надгортанное устройство или интубация трахеи, коникотомия.

# B. Дыхание

Последовательность лидера одинакова во всех ситуациях: **эффективность дыхания → симметричность трахеи и состояние вен шеи → осмотр грудной клетки → аускультация в шести точках → перкуссия в шести точках.** Меняется только работа адъютора.

| Ситуация | Адъютор |
|---|---|
| **Дыхание эффективное** | Пульсоксиметрия с началом осмотра грудной клетки |
| **Дыхательная недостаточность I–II степени** | Пульсоксиметрия → ингаляция кислорода |
| **Дыхательная недостаточность III–IV степени или брадипноэ** | Пульсоксиметрия → вентиляция дыхательным мешком, подключённым к источнику кислорода |
| **Напряжённый пневмоторакс** | Пульсоксиметрия → ингаляция кислорода → пункция плевральной полости выполняется лидером или адъютором по указанию лидера → продолжение ингаляции кислорода; лидер повторно проводит аускультацию и перкуссию |

Оценка эффективности дыхания — правило «вижу — слышу — ощущаю» за 10 секунд при открытых дыхательных путях: экскурсия грудной клетки, звуки изо рта, движение воздуха. Число вдохов за 10 секунд умножается на 6.

| Частота дыхания | Трактовка |
|---|---|
| 8–32 в минуту | Дыхание эффективное |
| Менее 8 либо более 32 в минуту | Дыхание неэффективное: требуется респираторная поддержка немедленно |

Точки аускультации и перкуссии: второе-третье межреберье по средней ключичной линии, пятое-шестое по передней подмышечной, шестое-седьмое по задней подмышечной — симметрично с двух сторон.

# C. Кровообращение

Последовательность лидера: **пульс на сонной и лучевой артерии одновременно → сравнительная оценка пульса на лучевых артериях → симптом белого пятна → аускультация тонов сердца с оценкой дефицита пульса → регистрация ЭКГ в 12 отведениях и сбор анамнеза.** Распределение остального зависит от того, кто регистрирует ЭКГ.

::: roli3
| Вариант | Лидер | Адъютор |
|---|---|---|
| **Первый** | Пульс, симметричность, белое пятно, тоны сердца; затем регистрация ЭКГ и сбор анамнеза | Измерение артериального давления после оценки симметричности пульса; сосудистый доступ во время регистрации ЭКГ |
| **Второй** | Пульс, симметричность, белое пятно, тоны сердца; измерение артериального давления; сбор анамнеза | Регистрация ЭКГ в 12 отведениях и обеспечение сосудистого доступа |
:::

Артериальное давление измеряется **только после** оценки симметричности пульса: раздувание манжеты искажает результат сравнительной оценки. При выявленной асимметрии давление измеряется на обеих руках.

| Находка | Ориентировочное значение |
|---|---|
| Пульс есть на лучевой артерии | Систолическое давление более 80 мм рт. ст. |
| Пульс только на сонной артерии | Систолическое давление более 40 мм рт. ст. |
| Время капиллярного наполнения до 3 с | Норма |
| Время капиллярного наполнения более 3 с | Циркуляторные нарушения |

При признаках нарушения гемодинамики инфузия кристаллоидами начинается сразу после обеспечения доступа, не дожидаясь окончания осмотра.

# D. Неврологический статус

::: roli
| Лидер | Адъютор |
|---|---|
| Оценка по шкале комы Глазго (учитывается лучший ответ, полученный за весь осмотр) | Глюкометрия |
| Зрачки: размер, симметричность, прямая и содружественная реакция на свет | Подготовка препаратов по указанию лидера |
| Моторный дефицит: мышечный тонус попарно на верхних и нижних конечностях, мышечная сила при достаточном уровне сознания | Терапия по показаниям по указанию лидера |
| Менингеальные симптомы: ригидность затылочных мышц сразу после оценки зрачков, симптомы Кернига и Брудзинского вместе с оценкой тонуса | |
:::

**Глюкометрия обязательна при любом нарушении сознания.**

# E. Общий осмотр

::: roli
| Лидер | Адъютор |
|---|---|
| Осмотр и пальпация живота в четырёх точках: симметричность, участие в дыхании, повреждения, боль и напряжение | Термометрия — начинается в начале этапа, поскольку требует времени; при подозрении на гипотермию ректально либо в паховой складке |
| Сравнительная пальпация пульса на бедренных артериях: симметричность, наполнение | |
| Осмотр конечностей: кожа, повреждения, отёки, варикозно расширенные вены | |
| Кожа и слизистые на участках, не осмотренных ранее: цвет, влажность, сыпь, пролежни, рубцы, повреждения | |
| Осмотр спины в устойчивом боковом положении | Помощь в повороте пациента |
| Ректальное исследование по показаниям: признаки шока в рамках поиска источника кровотечения | Утилизация отходов, оформление документации |
:::

# После осмотра

| Действие | Кто | Содержание |
|---|---|---|
| Повторный осмотр | Лидер | Только те области и системы, где выявлены отклонения или требуется уточнение |
| Мониторинг | Адъютор | ЭКГ-мониторинг, артериальное давление, сатурация, капнометрия; при критическом состоянии регистрация ЭКГ на бумажном носителе каждые 5 минут |
| Терапия | Лидер назначает, адъютор выполняет | По приказу ДЗМ Москвы № 535 от 18.05.2023 в соответствии с выявленным состоянием |
| Дополнительные исследования | По решению лидера | Ультразвуковое исследование, капнометрия, экспресс-тесты, анализ крови — при показаниях и технической возможности |
| Решение о маршруте | Лидер | Медицинская эвакуация, вызов бригады «на себя», дистанционный консилиум |
| Эвакуация | Оба | Непрерывный мониторинг и продолжение терапии в пути |

# Положения, в которых теряются баллы и время

- Артериальное давление измерено до сравнительной оценки пульса — сравнительная оценка обесценена.
- Перкуссия пропущена: по протоколу она обязательна, в шести точках, симметрично.
- Термометрия оставлена на конец осмотра — её результат не успевает появиться.
- Глюкометрия не выполнена при нарушении сознания.
- После вмешательства не проведена повторная оценка того же параметра: выдвинули челюсть — заново оценили проходимость, выполнили пункцию — заново выслушали и перкутировали.
- Оценка по шкале комы Глазго выставлена по одному моменту, а не по лучшему ответу за весь осмотр.
- Роли не распределены до входа к пациенту, и оба выполняют одно и то же.
- Результат доложен без числа.
