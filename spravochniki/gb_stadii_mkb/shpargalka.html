Стадия — по ПОМ и АКС. От уровня АД не зависит.

Стадия берётся наихудшая из анамнеза / ЕМИАС и обратно не понижается.
I стадия

Нет ПОМ, нет АКС. Могут быть только факторы риска (курение, дислипидемия, ожирение…).

КодЧто обычно значит на линии
I10Эссенциальная гипертензия без указанного поражения органов

Если в карте только I10 и нет ИМ / инсульта / ХСН / ФП / тяжёлой ХБП / ГЛЖ — пиши ГБ I ст.

II стадия

Есть бессимптомное ПОМ (или ХБП С3, или СД без поражения органов). АКС нет.

КодОриентир ПОМ
I11.9ГБ с поражением сердца без ХСН (часто = ГЛЖ)
I12.9ГБ с поражением почек без ХПН
N18.3ХБП 3 ст. (СКФ 30–59) — ПОМ
E11.9 / E11.8СД 2 без осложнений — сам по себе не III
I67.2Церебральный атеросклероз — не автоматом III
I67.8«Другие поражения сосудов мозга» — без инсульта/ТИА не АКС

ПОМ по КР ещё: ГЛЖ (ЭКГ/Эхо), альбуминурия 30–300, ЛПИ <0,9, СПВ >10, пульсовое ≥60 у пожилых, выраженная ретинопатия.

III стадия

Есть АКС (и/или ХБП тяжёлая, и/или СД с поражением органов).
