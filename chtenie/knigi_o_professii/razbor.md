Список литературы о медицине, работе с пациентами и профессиональной среде. Не учебники: клиническая литература собрана отдельно, в списке «Профессиональная литература».

Большинство зарубежных изданий выходило в русском переводе; наличие перевода уточняется по каталогам издательств. Список дополняется.

# Оговорка

Список отражает выбор авторов проекта и не является обязательным перечнем. Часть изданий содержит описания клинических случаев, устаревшие по современным представлениям; клинические сведения следует проверять по действующим руководствам и протоколам.
